# swim-cv

Swimming-video human pose estimation demo based on RTMPose.

## Local data policy

Raw videos, model weights, inference outputs, and IDE settings are intentionally
ignored by Git. They remain only on the local machine unless explicitly shared.

## Project layout

```text
src/       Processing and inference scripts
tests/     Automated tests
input/     Local input videos (ignored)
video/     Local input videos (ignored)
models/    Downloaded model assets (ignored)
output/    Generated results (ignored)
```
